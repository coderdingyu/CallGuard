# AI 伪造语音检测拓展

AI 伪造语音检测可以提升 CallGuard 的安全产品感，但它不应替代当前主线。当前主线是中文通话风险预警：ASR、文本风险、音频风险、压力识别和 CAEF 融合。

## 适合作为拓展的原因

- 诈骗电话中可能出现 TTS、声音克隆或变声。
- 伪造语音概率可以作为额外安全信号，帮助判断“对方声音是否可信”。
- 该方向技术含量高，但需要独立数据集和独立评测，直接塞进当前模型容易让题目发散。

## 推荐实现路线

1. 数据准备

准备真实语音、TTS 语音、声音克隆语音和 replay 录音。数据来源要多样，否则模型容易只学到某个合成器的痕迹。

2. 特征与模型

从频谱、相位、能量稳定性、静音段、说话人一致性等角度提取特征。早期可以使用传统特征 + 轻量分类器，后期再尝试 wav2vec2、AST 或 AASIST 类模型。

3. 产品接入

不要把伪造检测作为“诈骗判断”的唯一依据，而是新增一个字段：

```text
spoof_score: 0.0 - 1.0
```

再把它作为 CAEF 的辅助安全信号：

```text
综合风险 = 通话风险 + 文本风险 + 压力信号 + 伪造语音信号
```

4. 评测指标

建议报告：

- accuracy
- macro F1
- EER
- spoof recall
- 不同合成器/不同说话人的泛化表现

## 汇报时的表述

可以把它放在“未来工作”中：

CallGuard 当前聚焦中文通话风险预警，未来可以加入 AI 伪造语音检测，将 TTS/声音克隆概率作为独立安全信号接入 CAEF，从而进一步识别冒充熟人、冒充客服或冒充公检法的高风险通话。
