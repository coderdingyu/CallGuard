# CallGuard 课程报告提纲

## 题目

CallGuard：面向电话诈骗与通话压力场景的多模态风险预警系统

## 1. 待解决的问题

现实生活中，诈骗电话常常通过冒充客服、银行、公检法、快递等身份制造紧迫感，诱导用户转账、下载 App、提供验证码或银行卡信息。普通用户在通话当下容易受到压力影响，难以及时判断风险。

本项目希望用机器学习构建一个通话风险预警产品：用户上传或录制通话音频后，系统自动转写语音，分析音频特征和文本话术，输出可解释的风险分数、风险因素和安全建议。

## 2. 为什么适合用机器学习

该问题不是简单的关键词匹配，因为诈骗电话在表达方式、语气、身份包装和通话上下文上都有变化。机器学习可以从数据中学习正常通话与风险通话之间的统计差异，并与规则方法互补。

当前项目采用三类方法：

1. ASR 语音识别：使用本地 faster-whisper-base 将中文通话音频转成文本。
2. 音频风险模型：提取 MFCC、能量、过零率、频谱质心等传统语音特征，训练 Logistic Regression 二分类模型。
3. 文本风险模型：基于 ASR 文本训练 TF-IDF 字符 n-gram + Logistic Regression 模型，并结合关键词规则增强可解释性。

## 3. 数据集与处理

核心数据集使用 TeleAntiFraud 二分类子集：

- 训练集：4000 条
- 测试集：400 条
- 标签：normal / fraud
- 音频文件：已下载并解压到本地

由于二分类数据没有提供干净人工转写文本，项目使用 faster-whisper-base 对部分音频生成 ASR 文本，再训练文本 baseline：

- ASR 文本训练样本：240 条
- ASR 文本测试样本：80 条

## 4. 当前实验结果

音频 baseline：

- 模型：传统音频特征 + Logistic Regression
- Accuracy：0.7175
- Macro F1：0.7142
- Fraud Recall：0.8250

文本 baseline：

- 模型：TF-IDF 字符 n-gram + Logistic Regression
- Accuracy：0.9500
- Macro F1：0.9499
- Weighted F1：0.9499

融合策略：

- 对比 baseline：65% 音频风险 + 35% 文本风险
- 本文方法：CAEF 置信度感知可解释融合
- 文本高置信时抑制较弱音频；文本不确定时动态引入音频
- 规则分支进行繁简归一化，模型分支保留原始 ASR 文本

本文方法实验结果：

- Fixed 65/35 Macro F1：0.8249
- CallGuard CAEF Macro F1：0.9246
- Text-only Macro F1：0.9499

CAEF 显著优于固定融合，但未超过当前最强文本单模态。这说明多模态并非简单相加，必须根据模态可靠性进行门控。

典型案例中，文本模型分数为 0.4907，单独使用文本会漏报；音频模型分数为 0.9628。CAEF 动态分配 32.76% 音频权重和 67.24% 文本权重，最终分数提升到 0.6454，成功识别为风险通话。

## 5. 产品设计

前端不是 Streamlit 或 Gradio，而是 Next.js 产品界面。用户可以上传音频、输入或修正通话文本，并看到：

- 综合风险分数
- 音频风险分数
- 文本风险分数
- 自动转写结果
- 关键词风险因素
- 文本模型证据词
- 可执行的安全建议

后端使用 FastAPI，提供音频分析、文本分析、ASR 转写和通话融合分析接口。

## 6. 难点与挑战

1. 中文高质量诈骗通话数据较少，公开数据集规模有限。
2. ASR 转写可能出错，尤其在噪声、口音、多人通话场景下。
3. 电话诈骗风险不等于“说谎检测”，产品表述必须谨慎，避免过度承诺。
4. 仅凭前 5 秒音频特征难以完整理解通话上下文。
5. 文本模型目前使用 ASR 伪转写训练，后续需要更多人工校正文本。

## 7. 后续优化方向

1. 增大 ASR 转写训练样本规模。
2. 引入中文预训练文本模型，如 MacBERT、RoBERTa-wwm 或通义/千问 embedding。
3. 引入 wav2vec2、HuBERT 等预训练语音表示。
4. 加入时间轴分析，显示风险在通话中的出现位置。
5. 加入录音功能和本地隐私保护策略。

## 8. 总结

CallGuard 将机器学习方法落到一个完整的产品原型中：它不仅能给出分类结果，还能展示转写文本、模型证据、关键词因素和安全建议。相比单纯训练一个分类器，这种形态更接近真实应用，也更适合作为机器学习课程大作业展示。
